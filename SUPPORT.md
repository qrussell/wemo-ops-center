# Getting help

Wemo Ops Center is free and maintained by one person in their spare time. There is no paid support, but there are good places to get help.

1. **Read the docs.** The [wiki](https://github.com/qrussell/wemo-ops-center/wiki) covers installation, setting up devices, schedules, the server and Docker, integrations, and has [Troubleshooting](https://github.com/qrussell/wemo-ops-center/wiki/Troubleshooting) and an [FAQ](https://github.com/qrussell/wemo-ops-center/wiki/FAQ).
2. **Ask in [Discussions](https://github.com/qrussell/wemo-ops-center/discussions).** Use **Q&A** for "how do I...?" questions. Other users with the same devices often know the answer. Discussions is also the place for Home Assistant, Homebridge, hubs and network setups.
3. **Report a bug** with the [bug report form](https://github.com/qrussell/wemo-ops-center/issues/new/choose) when something doesn't work as documented. Include your version, edition, operating system, device model and firmware, and the log.
4. **Tell us about your device** with the [device report form](https://github.com/qrussell/wemo-ops-center/issues/new?template=device_report.yml), whether it works or not.

**Security problems:** never post them publicly. Follow [SECURITY.md](SECURITY.md).

Belkin no longer supports Wemo devices, and this project isn't affiliated with Belkin, so please don't contact Belkin about Wemo Ops Center.

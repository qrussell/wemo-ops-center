ENGINEERED FOR HOMELABS

Core Capabilities Built to Rescue Every Wemo

Purpose-built network tooling that goes far beyond what Belkin's official app ever offered.

Universal Wi-Fi Provisioner

Connect directly to any factory-reset device's Wemo.Mini.xxx setup SSID, push Wi-Fi credentials completely offline, auto-handle legacy vs. newer firmware encryption, and save Wi-Fi profiles for rapid batch onboarding.

Inter-VLAN & Multi-Subnet Scanning

Combines instant SSDP broadcast discovery with deep multi-threaded sweeps across saved IoT subnets (e.g., 192.168.20.0/23) and Direct IP mode—automatically skipping VPN, VM, and Docker bridge interfaces.

Digital HomeKit Code Extractor

Lost the tiny paper sticker on the back of your plug? Query supported Wemo firmware directly over local UPnP to recover and display the formatted 8-digit Apple HomeKit pairing PIN in one click.

Local & Solar Automation

Keep porch lights and routines running reliably with a persistent background service supporting fixed daily schedules and astronomical sunrise/sunset triggers calculated locally from your latitude and longitude.

Hardware Rescue & Maintenance

Clear personal info (names, icons, stale cloud rules), wipe Wi-Fi credentials to re-enter setup mode, execute full factory resets, and set each device's clock and time zone so schedules stored on the plug run on time.

Cross-Platform & ARM64 Ready

Automated CI builds cover Windows, macOS, Linux desktops, Raspberry Pi OS (ARM64), and multi-arch Docker containers—running effortlessly on spare Pis, NAS boxes, or daily workstations.

Device Clock Sync

Wemo plugs keep their own clock for schedules and away mode stored on the device. Sync one device or all of them from the desktop app, tap Sync Clocks Now in the mobile web app, or let the background service do it once a day.

Insight Power & Dimmer Control

Insight plugs show their current draw in watts and today's energy in kWh, on the desktop Dashboard and in the mobile web app. Dimmers get a brightness slider in both.

Mobile Web App & Remote Server

Scan a QR code to control devices and schedules from your phone. Point the desktop app at a Wemo Ops Server on a Raspberry Pi, NAS or Docker host and it uses that server's devices and schedules. LAN only: no login, so never port-forward it.

Up and Running in Under 60 Seconds

Choose your platform below to copy ready-to-run commands or grab the latest pre-built release.

Always-On Server via Docker (x86_64 & ARM64)

Uses --network host for SSDP multicast discovery and exposes the Mobile Web UI on port 5050. Run it on a Linux host (Raspberry Pi, NAS, VM): Docker Desktop on Windows/macOS misses devices, so use the desktop app there. Set TZ to your time zone so schedules and device clock sync use local time.

Recommended for Homelabs 
# Pull and run the Always-On Wemo Ops Server on port 5050
docker run -d \
  --name wemo-ops-server \
  --network host \
  --restart unless-stopped \
  -e PORT=5050 \
  -e TZ=America/New_York \
  -v wemo_ops_data:/data \
  ghcr.io/qrussell/wemo-ops-server:latest
Open http://<server-ip>:5050 on any LAN browser or phone. Release Notes →

Linux Desktop & Raspberry Pi OS (systemd Service)

Install the wemo-ops package from the qrussell repository (x86-64 and ARM64). It contains the desktop app and the always-on server, which starts as the wemo-ops-server systemd service.

# Ubuntu / Debian / Mint / Raspberry Pi OS: add the signed qrussell repository once
sudo curl -fsSL https://qrussell.github.io/qrussell-repo/deb/qrussell-repo.gpg -o /usr/share/keyrings/qrussell-repo.gpg
echo "deb [signed-by=/usr/share/keyrings/qrussell-repo.gpg] https://qrussell.github.io/qrussell-repo/deb ./" | sudo tee /etc/apt/sources.list.d/qrussell.list
sudo apt update && sudo apt install wemo-ops

# Fedora 41+ / RHEL / Rocky / Alma (see the README for dnf 4)
sudo dnf config-manager addrepo --from-repofile=https://qrussell.github.io/qrussell-repo/qrussell.repo
sudo dnf install wemo-ops

# Desktop app: "WemoOps" in your app menu. Always-on server + web UI on port 5050:
systemctl status wemo-ops-server

Windows 10 / 11 Installer

Zero Python setup required. Download WemoOps_Setup_v<version>.exe from GitHub Releases. It installs to Program Files and adds a Windows Firewall rule so phones on your home (Private) network can open the mobile web app. SmartScreen warning on first launch: More info → Run anyway.

# PowerShell: open the latest release and download WemoOps_Setup_v<version>.exe
Start-Process "https://github.com/qrussell/wemo-ops-center/releases/latest"

# Optional: check the download against SHA256SUMS.txt from the same release
Get-FileHash .\WemoOps_Setup_v*.exe -Algorithm SHA256
